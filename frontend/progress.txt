Project Progress Update – VeriUnlearn (Frontend System)

We have successfully developed the frontend prototype of a Verifiable Machine Unlearning System, focused on simulating GDPR-compliant data deletion with transparency, auditability, and user interaction.

The system is built as a dashboard interface that allows users to initiate deletion requests and observe the corresponding system response, verification proof, and activity history.

Key Features Implemented

User Deletion Interface
Users can input a User ID and initiate a deletion request
System provides real-time feedback (processing, success, or error)
Simulates backend behavior for testing and demonstration
Dynamic Logging System
Every deletion request is stored as a log entry
Logs are updated in real time
Includes search/filter functionality and clear logs option
Ensures traceability of actions
Proof Generation System
Each deletion generates a verification proof
Includes user ID, unique hash, timestamp, and status
Represents the concept of verifiable unlearning
Proof History (Audit Trail)
All generated proofs are stored and displayed
Enables tracking of deletion activity over time
Mimics audit and compliance systems
Exportable Proof Feature
Users can download proof files containing deletion details
Simulates compliance documentation
Data Visualization (Analytics)
Integrated charts to display deletion activity
Shows number of deletions per user
Updates dynamically based on system actions
Modern Dashboard UI
Built using React and Tailwind CSS
Includes sidebar navigation and card-based layout
Clean, responsive, and interactive interface

Technical Highlights

State management using React hooks
Dynamic UI updates and event handling
Simulation of asynchronous backend operations
Data filtering and search implementation
Chart integration for analytics
Structured and modular frontend design

Current System Flow

User → Dashboard Interface → Mock Backend Logic → Logs and Proof Generation → Visualization

Backend integration will replace the mock logic in the next phase.

Summary

The current implementation represents a fully functional frontend prototype demonstrating the core concepts of verifiable machine unlearning, including transparency, proof generation, audit tracking, and data visualization.

This system is now ready for backend integration and further validation in the next phase of development.
